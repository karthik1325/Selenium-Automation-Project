# Demo Web Shop – Selenium Automation Project

## Overview
Automation testing project for an e-commerce demo application, 
covering Login, Product Search, and Cart functionalities.

## Tech Stack
- Java
- Selenium WebDriver
- TestNG
- Maven
- Page Object Model (POM)

## Modules Automated
- User Login/Authentication
- Product Search
- Add to Cart

## How to Run
1. Clone the repo
2. Import as Maven project
3. Run TestNG suite (testng.xml)
